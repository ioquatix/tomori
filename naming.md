# Naming

**Tomori** (`ともり`, with `灯` as a light-associated name spelling) is the
name of both the system and its conversational coordinator. One cohesive name
connects the shared workspace to the presence you speak with inside it.

The lamplight association suggests a steady central presence: a light to gather
around. The intended spelling is **Tomori**, not "Tamori".

## Theme

A Japanese-inspired environment is a proposed visual direction: a small shrine
around the central coordinator, floating clouds, a night sky and a distant
moon. A fixed sky or a cycle in a chosen timezone remain options. These are
design ideas, not implemented scenery or a finalized architectural treatment.

## Scope

The public repository uses `ioquatix/tomori`. Existing Cargo packages, Android
application IDs, process names and discovery identifiers have not been renamed.
Any technical renaming should be planned separately to preserve compatibility.
